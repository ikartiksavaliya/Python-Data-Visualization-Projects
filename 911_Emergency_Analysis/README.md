# 911 Emergency Calls Analysis

## Overview
This project analyzes a dataset of 911 emergency calls (sourced from Kaggle/Montgomery County, PA). The goal is to visualize call patterns, categorize emergencies, and identify temporal trends.

## Key Insights
* **Top Call Types:** Identified the most common reasons for 911 calls (EMS, Traffic, Fire).
* **Temporal Analysis:** Visualized call volume by hour, day of the week, and month.
* **Location Analysis:** Determined the top zip codes and townships for emergency calls.
* **Heatmaps:** Created heatmaps to show call density during specific times of the day and week.

## Files
* `911.csv`: The raw dataset containing call details (lat, lng, desc, zip, title, timeStamp, twp, addr, e).
* `Analysis_Notebook.ipynb`: The Jupyter Notebook containing the code for data cleaning, processing, and visualization. *(Rename this to your actual notebook name if different)*.

## Visualizations
* Countplots for Call Reasons.
* Line charts for monthly trends.
* Heatmaps for daily/hourly activity.

## Usage
Open the notebook in Jupyter to view the interactive analysis and plots.
